# @grupo-mirassol/ilc-design-system

Angular library shared by Grupo Mirassol applications and distributed through GitHub Packages.

## Code scaffolding

Run `ng generate component component-name --project ilc-ui` to generate a new component. You can also use `ng generate directive|pipe|service|class|guard|interface|enum|module --project ilc-ui`.
> Note: Don't forget to add `--project ilc-ui` or else it will be added to the default project in your `angular.json` file. 

## Build

Run `ng build ilc-ui` to build the project. The build artifacts will be stored in the `dist/` directory.

## Publishing

After building your library with `ng build ilc-ui`, go to the dist folder `cd dist/ilc-ui` and run `npm publish --registry=https://npm.pkg.github.com`.

## Running unit tests

Run `ng test ilc-ui` to execute the unit tests via [Karma](https://karma-runner.github.io).

## Further help

To get more help on the Angular CLI use `ng help` or go check out the [Angular CLI Overview and Command Reference](https://angular.io/cli) page.
