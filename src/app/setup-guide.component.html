Configure o acesso ao GitHub Packages uma vez e siga as etapas para usar a biblioteca em um novo app Angular.

  1. Crie um projeto Angular standalone

    Use Angular 18 ou superior e entre na pasta criada.

    npx @angular/cli@18 new meu-app --standalone
cd meu-app

  2. Configure o acesso ao pacote privado

    Crie um arquivo .npmrc na raiz do projeto. O token precisa ter permissão read:packages; mantenha-o em uma variável de ambiente ou secret de CI e nunca o versione.

    @grupo-mirassol:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${NODE_AUTH_TOKEN}

  3. Instale o design system e os peers do Material

    npm install @grupo-mirassol/ilc-design-system @angular/animations@^18 @angular/cdk@^18.2 @angular/material@^18.2

  4. Carregue tokens e tema globalmente

    Adicione uma vez ao arquivo src/styles.scss:

    @use '@grupo-mirassol/ilc-design-system/tokens/ilc-tokens';
    @import '@angular/material/prebuilt-themes/azure-blue.css';

  5. Registre as animações do Angular Material

    Necessário para os componentes Material usados por formulários e diálogos. Adicione o provider à configuração existente em src/app/app.config.ts:

    import { provideAnimations } from '@angular/platform-browser/animations';

providers: [provideAnimations()]

  6. Importe o módulo e use um componente

    Em um componente standalone, importe IlcUiModule e use o seletor no template:

    import { Component } from '@angular/core';
    import { IlcUiModule } from '@grupo-mirassol/ilc-design-system';

    @Component({
  standalone: true,
  imports: [IlcUiModule],
  template: '<ilc-button color="primary">Salvar</ilc-button>',
    })
    export class AppComponent {}
